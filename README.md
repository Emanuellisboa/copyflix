# 🎬 Copyflix — Netflix Clone

Clone da interface da Netflix com seleção de perfis, catálogo personalizado e dark/light mode.

🔗 **[Ver projeto ao vivo](https://emanuellisboa.github.io/copyflix/)**

---

## ✨ Funcionalidades

- Seleção de perfis com animação de hover
- Dark/Light mode com preferência salva
- Intro animada ao entrar no perfil
- Catálogo personalizado por perfil
- Preview de vídeo ao passar o mouse nos cards
- Design responsivo (desktop, tablet e mobile)

---

## 🛠️ Tecnologias

- HTML5
- CSS3 (variáveis, grid, flexbox, animações)
- JavaScript vanilla
- LocalStorage para persistência de dados
